# Dataset Directory

This directory stores the transaction data for the E-Commerce Customer Analytics system.

### Raw Dataset Source
* **Official Source:** [UCI Machine Learning Repository - Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)
* **File Name:** `online_retail.xlsx`

If downloading manually, place `online_retail.xlsx` into this `dataset/` folder.

### Preprocessed Dataset Included
* **File Name:** `online_retail_cleaned.parquet` (3.1 MB)
* Contains all 392,692 cleaned and validated transactions.
* Pre-included in the repository so the Jupyter notebook and Streamlit application run out of the box with zero delay.
